# Arquitectura de segurança

A autorização será aplicada no backend e combinará papel, unidade organizacional, departamento, tipo de dado e acção. Menor privilégio, auditoria e classificação da informação orientam o desenho futuro.

Não inserir dados reais, secrets ou documentos pessoais nesta fundação. Consultar também `SECURITY.md` e a skill `mepa-security`.
