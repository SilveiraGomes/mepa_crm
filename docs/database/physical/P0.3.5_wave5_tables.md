## Especificação por tabela

Cada bloco: **PK**, **public_id** (razão, se aplicável), **FKs** (alvo, on_delete/on_update), **UNIQUE**, **CHECK esperado** (por convenção do projecto — ver `04_database_constraints.md`: intervalos semiabertos `ends_at > starts_at`; sem CHECK entre tabelas, integridade de contexto académico é responsabilidade transaccional do serviço), **colunas importantes**, **status/lifecycle**, **ownership/scope**, **auditoria**, **dados sensíveis**.

### courses *(Wave 4, já física)*
PK `id`. public_id: sim (exposição em portal). FKs: nenhuma. UNIQUE: `code`, `public_id`. Colunas: `code, name, eligibility_policy_version, status`. Status: `DRAFT|...` (D-11 pendente para enum fechado). Ownership: MEPA Academia; reutilizado também por Discipulado (Wave 4). Auditoria: alteração de `eligibility_policy_version` deve gerar linha em `audit_logs`. Sensibilidade: Restrito.

### academic_units
PK `id`. public_id: não (registo interno). FK: `unit_id → organizational_units` (RESTRICT/RESTRICT). UNIQUE: `code`. Colunas: `unit_id, code, name, status`. Ownership: MEPA Academia, ancorado à árvore organizacional. Auditoria: criação/desactivação auditável. Sensibilidade: Restrito. **Nota:** tabela plana, sem hierarquia própria — ver gap "polo" na Secção 5 do relatório principal.

### programs
PK `id`. public_id: sim (URL de portal académico). FK: `academic_unit_id → academic_units` (RESTRICT/RESTRICT). UNIQUE: `code`, `public_id`. Colunas: `academic_unit_id, code, name, status`. Auditoria: criação/publicação. Sensibilidade: Restrito.

### curricula
PK `id`. public_id: não. FK: `program_id → programs` (RESTRICT/RESTRICT). UNIQUE: `(program_id, version)`. Colunas: `program_id, version, status, published_at`. CHECK esperado: `version >= 1`. Lifecycle: `DRAFT → PUBLISHED` (imutável após `published_at` preenchido — teste crítico C8). Auditoria: `curriculum.published` obrigatoriamente auditado (Secção 13 do relatório). Sensibilidade: Restrito.

### curriculum_courses
PK `id`. public_id: não. FKs: `curriculum_id → curricula`, `course_id → courses` (ambas RESTRICT/RESTRICT). UNIQUE: `(curriculum_id, course_id)`, `(curriculum_id, sequence)`. Colunas: `sequence, required`. Sensibilidade: Restrito.

### course_versions
PK `id`. public_id: não. FK: `course_id → courses` (RESTRICT/RESTRICT). UNIQUE: `(course_id, version)`. Colunas: `version, completion_policy_metadata (JSON), status`. Lifecycle: congelado por versão (ADR-0008/06_history_and_temporal_data.md). `completion_policy_metadata` guarda os parâmetros de conclusão sem exigir novo schema quando D-09 for resolvida. Sensibilidade: Restrito.

### course_prerequisites
PK `id`. public_id: não. FKs: `course_id → courses`, `required_course_id → courses` (ambas RESTRICT/RESTRICT). UNIQUE: `(course_id, required_course_id)`. Detecção de ciclos: responsabilidade de serviço (SQL não expressa aciclicidade). Sensibilidade: Restrito.

### course_modules
PK `id`. public_id: não. FK: `course_version_id → course_versions` (RESTRICT/RESTRICT). UNIQUE: `(course_version_id, sequence)`. Sensibilidade: Restrito.

### lessons
PK `id`. public_id: não. FK: `module_id → course_modules` (RESTRICT/RESTRICT). UNIQUE: `(module_id, sequence)`. Colunas: `name, required`. **Distinta de `class_sessions`** (conteúdo vs. ocorrência agendada). Sensibilidade: Restrito.

### resources
PK `id`. public_id: sim (link de vídeo/portal). FK: `file_id → files` (RESTRICT/RESTRICT, **nullable** — vídeo externo não usa `files`). UNIQUE: `public_id`. Colunas: `resource_kind, provider, external_id, external_url, duration_seconds, status`. Ownership: reuso directo do domínio Files (Secção 27). Sensibilidade: Restrito.

### lesson_resources
PK `id`. public_id: não. FKs: `lesson_id → lessons`, `resource_id → resources` (RESTRICT/RESTRICT). UNIQUE: `(lesson_id, resource_id)`, `(lesson_id, sequence)`. Colunas: `sequence, required`. Sensibilidade: Restrito.

### cohorts
PK `id`. public_id: sim. FKs: `academic_unit_id → academic_units`, `curriculum_id → curricula` (RESTRICT/RESTRICT). UNIQUE: `code`, `public_id`. Colunas: `name, starts_at, ends_at, status`. CHECK esperado: `ends_at IS NULL OR ends_at > starts_at`. Sensibilidade: Restrito.

### classes
PK `id`. public_id: sim (turma em portal/API). FKs: `cohort_id → cohorts` (nullable, RESTRICT/RESTRICT), `academic_unit_id → academic_units` (RESTRICT/RESTRICT), `course_version_id → course_versions` (RESTRICT/RESTRICT), **`location_id → physical_locations`** (nullable, RESTRICT/RESTRICT — **ACCEPTED em P0.3.5-A0.1**, ADR-0015 Decisão A). UNIQUE: `code`, `public_id`. Índice adicional: `ix_classes_location_id`. Colunas: `capacity, status`. **`unit_id → organizational_units` foi REJECTED** (P0.3.5-A0.1) por ser redundante face a `academic_unit_id → academic_units.unit_id` — não faz parte do desenho final. Precedência de localização: se uma `class_session` tiver `event_session_id` preenchido e esse evento tiver `event_locations`, essa localização prevalece para essa sessão específica sobre `classes.location_id` (que é apenas o local por defeito da turma). Lifecycle: `DRAFT → PUBLISHED → IN_PROGRESS → CLOSED | CANCELLED`. Ownership: âmbito de autorização de `ACADEMY_MANAGE`/`ACADEMY_TEACH` no `academic_unit_id`. Sensibilidade: Restrito.

### instructors
PK `id`. public_id: não. FK: `person_id → people` (RESTRICT/RESTRICT). UNIQUE: `person_id` (um perfil por Pessoa). Colunas: `status`. Confirma reuso de Person, sem exigência de membership (Secção 16). Sensibilidade: Restrito.

### class_instructors
PK `id`. public_id: não. FKs: `class_id → classes`, `instructor_id → instructors`, `source_document_id → legal_documents` (nullable) (todas RESTRICT/RESTRICT). Colunas: `appointment_kind` (implícito por convenção — coluna real observada: `status, starts_at, ends_at, reason, source_document_id`). CHECK esperado: `ends_at IS NULL OR ends_at > starts_at`. **Base recomendada para verificação de scope granular por turma** (Secção 8.2 do relatório — em vez de estender `scopes`). Sensibilidade: Restrito.

### enrollments
PK `id`. public_id: sim. FKs: `person_id → people`, `class_id → classes`, `approved_by → users` (nullable) (RESTRICT/RESTRICT). UNIQUE: `(person_id, class_id)`, `public_id`. Colunas: `enrolled_at, status`. **Sem FK para `memberships`/`member_number`** — confirma non-member support (teste crítico C1). Lifecycle: ver máquina de estados (Secção 12 do relatório). Ownership/scope: `ACADEMY_ENROLL`. Auditoria: `enrollment.approved`/`enrollment.withdrawn`/`enrollment.completed`. Sensibilidade: Restrito (Confidencial/R-MENOR se `person_id` tiver `child_profiles`).

### class_sessions
PK `id`. public_id: não. FKs: `class_id → classes`, `lesson_id → lessons` (nullable), `event_session_id → event_sessions` (nullable) (todas RESTRICT/RESTRICT). Colunas: `starts_at, ends_at, status`. CHECK esperado: `ends_at > starts_at`. **`event_session_id` nullable é a decisão de reuso parcial de eventos** (Secção 6 do relatório — Opção B). Sensibilidade: Restrito.

### academic_attendance
PK `id`. public_id: não. FKs: `enrollment_id → enrollments`, `class_session_id → class_sessions`, `recorded_by → users` (todas RESTRICT/RESTRICT). UNIQUE: `(enrollment_id, class_session_id)` — idempotência natural (teste crítico, Secção 16 do relatório). Colunas: `attendance_status, recorded_at`. Ownership/scope: `ACADEMY_ATTENDANCE`, verificado via `class_instructors` do actor. Sensibilidade: Restrito.

### assessments
PK `id`. public_id: sim (avaliação em portal). FKs: `course_version_id → course_versions`, `lesson_id → lessons` (nullable) (RESTRICT/RESTRICT). UNIQUE: `public_id`. Colunas: `name, max_score DECIMAL(9,4), pass_score DECIMAL(9,4), max_attempts INT UNSIGNED, weight DECIMAL(7,4), status`. **Valores de política (pesos/limites/nota de corte) dependem de D-09 — BLOCKED**; estrutura não bloqueada. Sensibilidade: Restrito.

### assessment_attempts
PK `id`. public_id: não. FKs: `assessment_id → assessments`, `enrollment_id → enrollments` (RESTRICT/RESTRICT). UNIQUE: `(assessment_id, enrollment_id, attempt_number)`. Colunas: `attempt_number, started_at, submitted_at, status, answers_metadata (JSON)`. Concorrência: `attempt_number` deve ser calculado em transacção com lock no serviço (Secção 10 do relatório). Sensibilidade: Restrito (`answers_metadata` é dado de avaliação individual).

### grades
PK `id`. public_id: não. FKs: `attempt_id → assessment_attempts`, `graded_by → users` (RESTRICT/RESTRICT). UNIQUE: `(attempt_id, version)` — **nunca UPDATE, apenas nova versão** (teste crítico C5). Colunas: `score DECIMAL(9,4), graded_at, status, reason`. Auditoria: `grade.recorded`/`grade.revised` obrigatórios. Sensibilidade: Restrito, visível apenas ao aluno, a `class_instructors` activo e a staff com `ACADEMY_GRADES_VIEW` com scope adequado.

### progress
PK `id`. public_id: não. FKs: `enrollment_id → enrollments`, `lesson_id → lessons` (RESTRICT/RESTRICT). UNIQUE: `(enrollment_id, lesson_id)`. Colunas: `completed_at, completion_ratio DECIMAL(7,4), source_version, status`. Natureza: cache derivada, reproduzível, **não é diploma por si só** (descrição do catálogo). Sensibilidade: Restrito.

### resource_progress
PK `id`. public_id: não. FKs: `enrollment_id → enrollments`, `resource_id → resources` (RESTRICT/RESTRICT). UNIQUE: `(enrollment_id, resource_id)`. Colunas: `watched_seconds, verified_at, status`. Sensibilidade: Restrito.

### certificates
PK `id`. public_id: sim (documento externo/validação). FKs: `enrollment_id → enrollments`, `approved_by → users`, `file_id → files` (todas RESTRICT/RESTRICT). UNIQUE: `public_id`, `token_hash`, `(enrollment_id, version)`. Colunas: `version, token_hash BINARY(32), issued_at, revoked_at, status`. **`token_hash` nunca é `public_id`** — reuso do padrão hash-only ADR-0009/0012 ("ULID não é segurança"). Lifecycle: `ISSUED → REVOKED` (nunca apagado). Ownership/scope: `ACADEMY_CERTIFY`, **distinta** de `ACADEMY_ASSESS` (Secção 36). Auditoria: `certificate.issued`/`certificate.revoked` obrigatórios. Sensibilidade: **Confidencial (proposto)** — documento oficial com validação externa.

### transcripts
PK `id`. public_id: sim. FKs: `person_id → people`, `curriculum_id → curricula`, `file_id → files`, `approved_by → users` (todas RESTRICT/RESTRICT). UNIQUE: `(person_id, curriculum_id, version)`, `public_id`. Colunas: `issued_at, status`. Sensibilidade: Restrito.

### transcript_lines
PK `id`. public_id: não. FKs: `transcript_id → transcripts`, `enrollment_id → enrollments`, `certificate_id → certificates` (nullable) (todas RESTRICT/RESTRICT). UNIQUE: `(transcript_id, enrollment_id)`. Colunas: `final_score DECIMAL(9,4), result_status`. Sensibilidade: Restrito.

## Mapa de FKs (Secção 53) — verificação de invariantes

- **0 ciclos indesejados:** `create_before_adding_cyclic_foreign_keys` está vazio para Wave 5 em `migration_waves.json`. Único par potencialmente cíclico (`course_prerequisites.course_id`/`required_course_id`, ambos para `courses`) é auto-referencial via tabela associativa, não um ciclo de FK entre tabelas distintas.
- **0 fake identity:** nenhuma tabela tem coluna de nome/e-mail/telefone própria; toda a identidade flui de `people`/`users`.
- **0 membership-as-person:** `enrollments`/`instructors` referenciam `people`, nunca `memberships`.
- **0 registo académico paralelo:** todas as 26 tabelas dependem, directa ou transitivamente, de `people`, `organizational_units`, `files`, `users`, `event_sessions` ou `legal_documents` — todas tabelas já existentes de Waves 1–4. Nenhuma FK aponta para uma tabela académica fora deste conjunto de 26.

## Dependências de sequenciamento (Secção 57/59 do catálogo físico)

Wave 5 depende fisicamente de: `people`, `organizational_units`, `users` (Wave 1); `files` (Wave 1); `legal_documents` (Wave 1); `event_sessions` (Wave 3, referência opcional); `courses` (Wave 4, já física). Todas já existem na base actual (127 tabelas físicas) — Wave 5 pode iniciar migrations assim que D-09 e as duas decisões da Secção 21 do relatório principal forem resolvidas.
