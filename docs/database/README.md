# Base de dados

O ERD físico e o dicionário de dados serão produzidos na próxima etapa P0. Não existem nesta fundação migrations de negócio nem dados reais.

## Grupos futuros

- Identidade;
- Membros;
- Estrutura;
- Ministério;
- Departamentos;
- Eventos;
- Evangelismo;
- Academia;
- Financeiro;
- Comunicação;
- Sistema.

As futuras migrations deverão preservar histórico, suportar a base nacional única, separar Pessoa de Membership e manter integridade contabilística.
