## 26. Achado adicional (não-bloqueante) — bug de infraestrutura de teste

`tools/test-infrastructure/mysql_instance.py`'s acção CLI `stop` não regista de facto o processo `mysqld` iniciado por uma invocação `init-start` anterior (o rastreio de `self.process` é apenas em memória, por instância Python, não persistido em ficheiro PID entre invocações separadas do CLI) — a chamada `stop` reportou `mysqld_stopped: true` sem enviar `mysqladmin shutdown`, deixando o `mysqld` de facto a correr. Detectado porque o `netstat`/`tasklist` pós-`stop` ainda mostrava a porta 3307 activa; corrigido manualmente nesta tarefa via `mysqladmin shutdown` directo, confirmado limpo. **Classificação ADR-0014: TEST_INFRA_DEBT, não-bloqueante** — não altera comportamento de produto, não produz falso PASS (o resultado json do `stop` é enganador mas nenhum teste de produto dependeu dele), não esconde falha de produto, não danifica recursos de outra corrida (a app DB em 3306 nunca foi afectada, confirmado), não invalida evidência crítica (toda a evidência desta tarefa foi obtida enquanto a instância estava genuinamente a correr, antes do `stop`). Não foi corrigido no ficheiro `mysql_instance.py` nesta tarefa (fora do âmbito de A1, que é sobre o schema de Academia, não sobre o harness V2 em si); fica registado para tratamento futuro.
