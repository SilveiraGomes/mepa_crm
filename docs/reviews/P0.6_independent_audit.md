# P0.6 — Independent Audit

## First decision — REJECTED

Audited HEAD: `864d223a393f695e1373be927862fdc2a58b88b6`.

The independent reviewer identified three PRODUCT/SECURITY blockers, four EVIDENCE blockers and one TEST_INFRA blocker:

1. a reusable synthetic E2E credential was versioned;
2. tree children were fetched before expansion;
3. intermunicipal moves did not propagate `municipality_id` to descendants;
4. STARTED/STOPPED verified evidence was absent;
5. Graphify provenance still pointed at the baseline;
6. schema parity did not compare INFORMATION_SCHEMA;
7. M1–M8 were in-memory source checks instead of on-disk mutation probes;
8. raw logs for build/PWA/lint/Auth/database-docs were absent.

## Remediation

Code remediation commit: `10ee42b999edddfbd37c541f0524c921afbcbef9`.

- E2E credentials now exist only in ignored `.tmp`, are removed after execution and their isolated database was destroyed with `STOPPED_VERIFIED`.
- `TreeChildren` mounts only after expansion; Playwright asserts zero `/children` requests before the click and five after expanding five levels.
- move propagates geographic municipality to every descendant inside the same locked transaction; an integration test moves a Center with a Congregation between municipalities.
- scope coverage now explicitly includes own unit, descendant, sibling, ancestor, other region, create parent and move target.
- schema parity compares 11 live INFORMATION_SCHEMA tables against the canonical catalog or defining migration: 105 columns, 64 index entries and 27 FKs, with zero mismatches.
- M1–M8 mutate real files on disk; 8/8 are detected and SHA-256 before/after proves byte-for-byte restoration.
- raw validation logs and STARTED_VERIFIED/STOPPED_VERIFIED attestations are versioned.
- Graphify was regenerated from remediation commit `10ee42b9`: 6566 nodes, 11777 edges, zero dangling.
