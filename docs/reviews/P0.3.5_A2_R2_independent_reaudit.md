## 2. A2R-01 — bypass de conclusão

`CompletionService::complete` e a transição genérica com `effect = COMPLETION` chamam a mesma regra, `CompletionEligibilityGuard::assertEligible`. `AcademicPolicyResolver::evaluateCompletion` tem um único chamador, dentro desse guard. A máquina de estados relê a transição sob lock e exige que o efeito declarado corresponda ao efeito já protegido pelo chamador.

| Caso | Resultado |
|---|---|
| Exploit original com actor apenas `ACADEMY_ENROLL` | Negado pelas duas vias |
| Apenas ENROLL | `NOT_AUTHORIZED` |
| Apenas ASSESS | `NOT_AUTHORIZED` |
| ENROLL + ASSESS sem atribuição | `CLASS_ASSIGNMENT_REQUIRED` |
| Autoridade completa, critérios não cumpridos | `COMPLETION_CRITERIA_NOT_MET` |
| Autoridade, scope, atribuição e critérios válidos | ALLOW |
| Efeito ausente, inválido, nulo ou contraditório | `POLICY_NOT_CONFIGURED` |
| `effect = NONE` | Não produz conclusão semântica |
| Vocabulário de estados renomeado | Mesmo comportamento; nomes não autorizam |
| Atribuição caduca antes do commit | Negado na revalidação final |

Após as negações, o estado e `lock_version` da matrícula ficaram inalterados, não houve audit de sucesso, não foi emitido certificado e o transcript mostrou o estado real sem conclusão.

**Resultado: A2R-01 = RESOLVED.**

## 3. A2R-02 — transcript e notas entre unidades

O alvo agregado é derivado de `curriculum`, `enrollments`, `classes` e `academic_units` persistidos. `AcademyScopeResolver::forTranscript` reúne a unidade do curriculum e todas as unidades contribuintes. A autorização é exigida para o conjunto completo. `TranscriptService` relê as linhas e recusa alteração de escopo durante a operação.

| Caso | Resultado |
|---|---|
| Pessoa com histórico apenas na unidade A; actor com `ACADEMY_GRADES_VIEW` em A | PASS; dados de A corretos |
| Contribuinte em B; actor autorizado apenas em A | `OUT_OF_SCOPE` |
| Histórico misto A+B; actor autorizado apenas em A | `OUT_OF_SCOPE` para a operação inteira; nenhum payload parcial |
| `academic_unit_id = A` enviado para alvo persistido em B | Negado; o payload não altera o alvo real |
| Actor autorizado em A e B | PASS; ambas as linhas corretas |
| Pessoa existente, inexistente ou referência malformada perante actor não autorizado | Mesma razão e mesmo contexto; sem enumeração nesta camada |

`transcript.issue` também aplica tudo-ou-nada e não grava `transcripts` nem `transcript_lines` quando uma unidade contribuinte fica fora do scope.

**Resultado: A2R-02 = RESOLVED.**

A propriedade é verificada antes do estado de disponibilidade, evitando um oráculo de estado para recursos de outra unidade.

### A2R2-E01 — limite conhecido do validador estático

- **Severity:** INFO.
- **Category:** EVIDENCE.
- **Reproduction:** colocar `assertCover` em código morto, depois de `return`, numa closure não chamada ou apenas numa string.
- **Expected:** não aplicável ao conjunto fechado M1–M5; a documentação A2.1 declara que o validador é estático e deve ser combinado com testes comportamentais.
- **Actual:** algumas variantes textuais passam no validador estático; todas falham nos testes comportamentais relevantes. `assertCover(null)` é detetado.
- **Impact:** o validador isolado não prova alcançabilidade geral. A cadeia exigida para esta fase, validador mais testes de runtime, deteta as variantes.
- **Affected operation:** `enrollment.create`, `enrollment.transition`, `attendance.record`.
- **Blocker:** não.
- **Recommended remediation:** opcionalmente migrar a análise para AST/CFG ou documentar todas as classes de código morto já cobertas pelos testes de runtime.
